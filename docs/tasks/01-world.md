# World builders

Assigned files: **world.py**. All other file changes need instructor assignment.

## First feature

Add a small two-block-high hill on the west side using existing grass and dirt materials.

## Acceptance checks

- All ground cells remain.
- additions are in bounds.
- the center spawn and crystal locations stay clear.
- player can climb the hill with jumping.

## Stretch goal

Add a small stone arch using existing materials.

## Explain and submit

Explain one function or data structure you changed. Run the game, test your feature, and complete docs/HANDOFF_TEMPLATE.md. Submit changed files only.
