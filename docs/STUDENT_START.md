# Your first session

1. Extract the instructor's current ZIP into your own local folder. Do not edit a shared live folder.
2. Follow README.md to install and run the game. Walk, jump, select a material, build, save, and load before editing.
3. Get ONE task card from the instructor.
4. Browser Claude: start a conversation and upload PROJECT_RULES.md, docs/CONTRACTS.md, your task card, and the current .py source files. Do not upload .venv, saves, or the entire installed dependency folder. If your Claude account has Projects, you may use a separate project for your team, but refresh its source files each session.
5. Claude Code: open this folder. CLAUDE.md points to the shared rules. Tell it your assigned card and files.
6. Use the prompt below. Read the plan, make a small change, run it, and explain what changed.

## Prompt to copy

We are working on Class Block World v0.1. Read the project rules, shared contracts, and task card I supplied. My task is [card name]. My assigned files are [files]. First explain the smallest change and how we can test it. Stay within those files. Help me understand the Python, and propose any shared-file changes for my instructor rather than making them.

## End of class

Copy docs/HANDOFF_TEMPLATE.md and complete it. Give the instructor only your changed source files and handoff. Keep an untouched copy of your starting version. Do not include .venv or personal saves. Next class, start from the instructor's newly combined release; do not keep using an old master copy.
